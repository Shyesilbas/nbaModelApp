# Artifact Registry

This file tracks all data, model, and report artifacts generated by this project.

## Production Artifacts

### Datasets
- `data/processed/team_model_ready_v3_{YYYY_YY}.csv` (and `.parquet`) — **ACTIVE TEAM MODEL-READY DATASET (V3)** (6 seasons: 2020-21 to 2025-26; 189 columns with continuous Elo, Dean Oliver Four Factors, schedule fatigue, deterministic playoff series metadata, and advanced box score features including 3PT regression delta, assist-to-turnover, havoc rate, foul rate, FT margin, block rate, and scoring diet distributions)
- `data/experimental/player_model_ready_v4_usg.csv` — **ACTIVE PLAYER MODEL-READY DATASET (V4)** (6 seasons, 165,988 rows; rolling/EMA form, usage, opponent allowance per position group, rest. CSV only: the stale parquet copy was removed on 2026-10-20 because nothing refreshed it)
- `data/season={YYYY-YY}/features/team_features.csv` — Season-scoped pre-game team features
- `data/season={YYYY-YY}/features/player_features.csv` — Season-scoped individual player features
- `data/production/core_players.csv` — Production source of truth for team core rotations
- `data/production/team_elo_initial_2026_27.json` — **ACTIVE 2026-27 OPENING ELO RATINGS** (Chained multi-season continuous Elo across 2020-2026, regressed by 25% towards 1500 with offseason roster talent turnover adjustments)


### Frontend Data Caches
- `data/frontend/nba_frontend.db` — **HIGH-PERFORMANCE INDEXED SQLITE STORE** compiled by `scripts/build_frontend_db.py`. Powers sub-millisecond point lookups for game details, team boxscores, player boxscores, and player historical logs with zero startup memory overhead.
- `data/season=YYYY-YY/raw/play_by_play/{GAME_ID}.json` — Source-of-truth structured play-by-play cache generated by `scripts/build_play_by_play.py`; includes quarter scores, enriched event rows, running player totals, assist metadata, and highlight badges. Current coverage is Finals-only for seasons already backfilled.
- `frontend/public/data/play_by_play/{GAME_ID}.json` — Frontend export copy consumed by the React game detail view. Regenerated/synced from the root `data/` PBP cache.
- `frontend/public/data/schedule_details_{YYYY_YY}.json` — Lightweight per-season game summary map generated from cached play-by-play files. Used by score cards for quarter scores, top scorers, and PBP availability without loading full event logs.

### Models
- `models/production/win_probability_model_v10.pkl` (and `v9` alias) — **ACTIVE PRODUCTION WIN MODEL** (uncalibrated logistic regression, 7 features: ELO_DIFF, IS_HOME, CLEAN_NET_RTG_DIFF_LAST_10, WINRATE_DIFF_LAST_10, REST_DIFF, IS_B2B, OPP_IS_B2B; chosen by expanding-window Brier over LightGBM and L1 logistic)
- `models/production/feature_columns_v10.json` (and `v9` alias) — WIN inference feature list (7 features, see `config/features/win_v10.yaml`)
- `models/production/model_metadata.json` — WIN model metadata (2025-26 holdout: 68.2% Acc, 0.745 AUC, 0.2051 Brier; walk-forward 2021-22..2025-26: 65.6% Acc, Brier 0.2141 vs 0.2157 for Elo + home court; 2025-26 is the easiest of those seasons)
- `models/production/score_model_v10_home_rtg.pkl` (and `v9` alias) — **ACTIVE PRODUCTION SCORE HOME RTG** (standardized RidgeCV on OFF_RTG_LAST_10 and OPP_DEF_RTG_LAST_10)
- `models/production/score_model_v10_away_rtg.pkl` (and `v9` alias) — **ACTIVE PRODUCTION SCORE AWAY RTG** (standardized RidgeCV on OFF_RTG_LAST_10 and OPP_DEF_RTG_LAST_10, away-team rows)
- `models/production/score_model_v10_pace.pkl` (and `v9` alias) — **ACTIVE PRODUCTION SCORE PACE** (standardized RidgeCV on PACE_LAST_10 and OPP_PACE_LAST_10)
- `models/production/score_model_v10_margin.pkl` (and `v9` alias) — **ACTIVE PRODUCTION SCORE MARGIN** (standardized RidgeCV on the WIN model's inputs; target is the actual final margin)
- `models/production/score_model_v10_ridge_total.pkl` (and `v9` alias) — SCORE Ridge total residual correction (playoff / back-to-back / rest indicators, fit on temporal OOF residuals against actual points)
- `models/production/score_model_v10_ridge_margin.pkl` (and `v9` alias) — SCORE Ridge margin residual correction (same indicators)
- `models/production/score_model_v10_metadata.json` (and `v9` alias) — SCORE metadata (trained 2020-21..2025-26; walk-forward 2021-22..2025-26 total MAE 14.90 vs 14.95 for a last-10 points baseline, margin MAE 10.97 vs 11.41; intervals from actual-point OOF residuals, overtime included)
- `models/production/player_v9_lgb_pts.pkl` — **ACTIVE PRODUCTION PLAYER PTS** (LightGBM, L1 objective)
- `models/production/player_v9_lgb_reb.pkl` — **ACTIVE PRODUCTION PLAYER REB** (LightGBM)
- `models/production/player_v9_lgb_ast.pkl` — **ACTIVE PRODUCTION PLAYER AST** (LightGBM)
- `models/production/player_v9_features.pkl` — PLAYER inference feature list (21 features from `config/features/player_v9.yaml`; position flags and opponent allowance come from `add_player_matchup_features`)
- `models/production/player_v9_metadata.json` — PLAYER metadata (trained 2020-21..2025-26; 2025-26 holdout MAE PTS 4.51 / REB 1.89 / AST 1.33 vs EMA-10 4.61 / 1.92 / 1.35; the Ridge residual correction was retired on 2026-10-20 because it raised PTS MAE every season)
- `models/production/clean_holdout_metrics.json` — 2025-26 metrics of the holdout copies (fitted without that season) recorded at promotion; the retrain gate compares challengers against these

### Evaluation & Benchmarks
- `reports/evaluation/multi_season_walk_forward_backtest.md` (and `.json`) — **ACTIVE MULTI-SEASON WALK-FORWARD BACKTEST** (5 unseen seasons 2021-22..2025-26; production WIN/SCORE/PLAYER configurations against Elo + home court, last-10 real points and EMA-10 baselines; regenerate with `python -m scripts.walk_forward_benchmark`)
- `reports/backtests/2026-10-20_review/` — offline walk-forward (`metrics.json`, per-season prediction parquets for 2023-24..2025-26) and the 2025-26 live replay through the API code with holdout models (`live_2025_26.parquet`: AUC 0.735, Brier 0.206, total MAE 15.46, margin MAE 11.42, 0 failures)
- `reports/evaluation/feature_ablation_study.md` (and `.json`) — **MULTI-SEASON FEATURE ABLATION STUDY** (Empirical marginal contribution of Dean Oliver Four Factors, shot diet distributions, and fatigue interactions on unseen seasons).
- `reports/operations/live_shadow_and_drift_report.md` (and `.json`) — **LIVE SHADOW & DRIFT REPORT** (Ongoing evaluation of logged shadow predictions against game outcomes with Kolmogorov-Smirnov drift tests).
- `data/predictions/shadow_predictions_log.jsonl` — **APPEND-ONLY SHADOW PREDICTION STORE** (Structured log with prediction_id, model version, timestamp, conformal ranges, and feature snapshots).
