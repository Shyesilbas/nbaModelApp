# NBA ML Project Outputs Directory

This directory contains human-readable reports, charts, and validation outputs generated by the preprocessing and feature engineering pipelines.

## Directory Structure

*   **[analysis/](file:///Users/serhat/agProjects/nbaModelApp/outputs/analysis/)**: Contains the active, generated reports for humans.
    *   `team_roster_report.md`: Discovered team rosters sorted by average minutes.
    *   `core_player_report.md`: Identifies Top 3 Core and Top 5 Secondary players for each team.
    *   `star_player_candidates.md`: Top 50 league-wide star ranking candidates based on Importance Score.
    *   `team_model_ready_v3_report.md`: Model validation dataset report with core player availability, features, and leakage warnings.
*   **[archive/old_reports/](file:///Users/serhat/agProjects/nbaModelApp/outputs/archive/old_reports/)**: Holds deprecated/older general project markdown reports.
    *   `real_data_pipeline_report.md`: Initial validation report for the raw player/team games loading step.
*   **[archive/deprecated_outputs/](file:///Users/serhat/agProjects/nbaModelApp/outputs/archive/deprecated_outputs/)**: Stores older/deprecated pipeline logs and validation reports.
    *   `team_model_ready_report.md`: Validation report for the V1 model dataset.
    *   `opponent_feature_report.md`: Validation report for the V2 opponent-aware model dataset.

> [!NOTE]
> All underlying structured datasets (CSV/Parquet) corresponding to these reports are saved under [data/analysis/](file:///Users/serhat/agProjects/nbaModelApp/data/analysis/) and [data/processed/](file:///Users/serhat/agProjects/nbaModelApp/data/processed/), which serve as the machine-friendly sources of truth.
